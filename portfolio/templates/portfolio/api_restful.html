O que é uma API RESTful?

Uma API RESTful permite a comunicação entre aplicações através de pedidos HTTP. Desta forma é possível consultar, criar, atualizar ou remover informação sem necessidade de interação direta com páginas HTML.

Os principais métodos utilizados são:

  • GET – obter informação;
  • POST – criar informação;
  • PUT – atualizar informação;
  • DELETE – remover informação.

Neste projeto foi utilizada a framework Django Ninja para desenvolver uma API RESTful associada ao universo Dungeons & Dragons.

Foram implementadas operações CRUD completas, filtros através de query parameters e paginação para melhorar a consulta dos dados.

Dungeons & Dragons

A aplicação foi inspirada no universo Dungeons & Dragons, permitindo gerir campanhas e outros elementos relacionados com o jogo.

Swagger

O Django Ninja gera automaticamente documentação Swagger para todos os endpoints da API. Através desta interface é possível testar pedidos, visualizar schemas e analisar respostas diretamente no navegador.

Conclusão

A construção desta API permitiu compreender os princípios das arquiteturas REST, a criação de endpoints CRUD, a utilização de schemas para validação de dados e a integração entre Django, Django Ninja e Swagger.
