O que é uma API RESTful?

Uma API RESTful permite a comunicação entre diferentes aplicações através do protocolo HTTP. Em vez de um utilizador interagir diretamente com páginas web, outras aplicações podem consultar, criar, atualizar ou remover informação através de endpoints específicos.

As APIs REST utilizam normalmente quatro operações fundamentais:

  • GET – obter dados;
  • POST – criar novos dados;
  • PUT – atualizar dados existentes;
  • DELETE – remover dados.

Neste projeto foi desenvolvida uma API RESTful utilizando Django Ninja, uma framework moderna construída sobre Django que simplifica a criação de APIs e gera documentação automática através do Swagger.

A API desenvolvida tem como tema o universo Dungeons & Dragons e permite gerir campanhas através de operações CRUD completas. Foram ainda implementados filtros através de query parameters e mecanismos de paginação para melhorar a consulta dos dados.

Dungeons & Dragons

A imagem apresentada representa uma sessão de Dungeons & Dragons com miniaturas e mapa de jogo. Esta temática foi escolhida para demonstrar a modelação de dados e a construção de uma API RESTful baseada em campanhas, personagens e outros elementos associados ao jogo.

Documentação Swagger

O Django Ninja gera automaticamente documentação Swagger para todos os endpoints criados. Através desta interface é possível testar pedidos diretamente no navegador, visualizar os schemas utilizados e verificar as respostas produzidas pela API.

Conclusão

A construção desta API permitiu compreender os princípios fundamentais das arquiteturas REST, a organização de endpoints CRUD, a utilização de schemas para validação de dados e a integração entre Django, Django Ninja e Swagger para documentação automática.
